# TheGauntletModel

A repository to house the The Gauntlet Model: a tool to explore the impacts of pinniped management on salmon survival. 

Start with the document "How to Run the Gauntlet Model.docx".

More information available [here.](https://lizallyn.github.io/thesis/)

This project was funded by an award from Washington Sea Grant to the Makah Tribe (R/HCE-28).
